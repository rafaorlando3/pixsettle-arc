PixSettle Ledger on Arc

USDC settlement for orders paid by Pix (simulated off-chain), with the exception rules enforced on-chain: one settlement per order, idempotent replays, refunds that block settlement, and post-settlement refunds tracked as exposure until the merchant returns the funds. Read-only: this page only calls eth_blockNumber, eth_getCode and eth_getLogs on a public Arc RPC. Every number below covers only the block range that was read. It is the whole contract history only when the address and start block match the deploy published in this page; otherwise the page says the earlier history was not checked.
